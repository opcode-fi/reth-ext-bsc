# engineering rules

THIS REPO IS PUBLIC. NOTHING HERE MAY NAME INTERNAL HOSTS, PATHS, SERVICES OR ADDRESSES.
`${BSC_DATADIR:-./data}` IS A DEFAULT, NOT A REAL PATH — KEEP IT THAT WAY. MEASUREMENTS ARE
WELCOME; THE MACHINE THEY WERE TAKEN ON IS NOT.

## WHAT THIS REPO IS
- IT IS THE ONLY REPO THAT MAY DEPEND ON **BOTH** `opcode-fi/reth-ext` AND `opcode-fi/reth-bsc`. THAT IS ITS ENTIRE REASON TO EXIST. IF A CHANGE DOES NOT NEED BOTH SIDES, IT BELONGS IN ONE OF THEM, NOT HERE.
- THE REX BRIDGE LIVES IN `opcode-fi/reth-bsc`. IT NEEDS `BscPrimitives`, SO MOVING IT HERE IS A DEPENDENCY CYCLE. DO NOT TRY.
- THE CONSUMER LIVES IN `opcode-fi/reth-ext` AND MUST STAY CHAIN-AGNOSTIC. DO NOT ADD BSC AWARENESS TO IT. IF SOMETHING DOWNSTREAM EVER NEEDS BSC BLOB SIDECARS, THE BSC-AWARE CONSUMER IS BUILT **HERE**.
- NO LIBRARY CODE. THIS CRATE IS DEPLOY, TESTS, EXAMPLES AND PROSE. IF YOU FIND YOURSELF WRITING A `src/lib.rs`, YOU ARE PUTTING IT IN THE WRONG REPO.

## COMMENTS
- **YOU ARE BANNED FROM WRITING COMMENTS IN CODE.** IF YOU WANT TO EXPRESS A PROPERTY, EXPRESS IT IN CODE. AN ESSAY OVER A LINE DOES NOT CHANGE ITS BEHAVIOUR, IT ONLY CONFUSES SUBSEQUENT AGENTS AND HUMANS.
- IN TESTS, ONE SENTENCE ON THE PROPERTY BEING ENFORCED IS ALLOWED.
- BANNED IN `Cargo.toml`.
- `deploy/` AND THE MARKDOWN ARE THE EXCEPTION, AND DELIBERATELY SO: STRANGERS RUN `deploy/` BLIND, AND EVERY NON-OBVIOUS VALUE THERE WAS SET IN RESPONSE TO A MEASURED FAILURE. A NUMBER IN `deploy/` WITHOUT ITS REASON IS A NUMBER THE NEXT PERSON WILL "TIDY" AND REGRESS.

## THE WIRE IS THE WHOLE POINT
- THE TWO SIDES ARE BUILT AGAINST DIFFERENT RETH GENERATIONS: `reth-ext` ON PARADIGMXYZ `v2.3.0`, `reth-bsc` ON BNB-CHAIN `v0.1.2`. THE BINCODE LAYOUT IS IDENTICAL TODAY. NOTHING ENFORCES THAT.
- THE FAILURE MODE IS SILENT. `rex-cons` SKIPS MESSAGES IT CANNOT DECODE AND HOLDS THE STREAM OPEN, SO DRIFT PRESENTS AS A HEALTHY CONNECTION DELIVERING NOTHING, FOREVER. THERE IS NO VERSION HANDSHAKE — `SubscribeRequest` IS EMPTY.
- THEREFORE: **A TEST THAT ONLY ASSERTS CONNECTIVITY IS WORSE THAN NO TEST.** IT PASSES STRAIGHT THROUGH THE FAILURE IT EXISTS TO CATCH. ASSERT THAT A NOTIFICATION DECODED, THAT IT CARRIES BLOCKS, THAT ITS EXECUTION OUTCOME LINES UP WITH THEM, AND THAT THE STREAM KEEPS DELIVERING.
- RUN THE GUARD AFTER **ANY** RETH BUMP ON EITHER SIDE. THAT IS THE ONE OBLIGATION THIS REPO HAS.

## TESTS
- ANY TEST NEEDING A LIVE NODE IS `#[ignore = "requires a running BSC node"]`. `cargo test` MUST STAY GREEN OFFLINE ON A FRESH CLONE.
- TESTS THAT ASSERT LANGUAGE PRIMITIVES WORK ARE BANNED. IF STATEMENTS WORK. SERDE SERIALIZES.
- DO NOT ASSERT BLOCK NUMBERS ARE CONTIGUOUS. A RECONNECT RESUMES AT THE LIVE TIP AND THE NODE COMMITS RANGES WHEN CATCHING UP — BOTH ARE LEGITIMATE. MONOTONIC IS THE PROPERTY; GOING BACKWARDS IS THE BUG.
- BSC PRODUCES A BLOCK EVERY ~0.45s. A TIMEOUT OF TENS OF SECONDS MEANS THE STREAM IS BROKEN, NOT THAT THE CHAIN IS QUIET. SIZE TIMEOUTS ACCORDINGLY.

## DEPLOY
- ALWAYS REBUILD. `docker compose restart` SHIPS THE OLD IMAGE AND IS AN EXCELLENT WAY TO SPEND AN HOUR DEBUGGING A FIX THAT WAS NEVER DEPLOYED. `deploy/run.sh` REBUILDS ON PURPOSE.
- NEVER `docker compose down --remove-orphans`. THIS PROJECT SHARES A HOST WITH OTHER SERVICES AND IT WILL TAKE THEM WITH IT.
- BEFORE CHANGING A VALUE IN `deploy/`, READ ITS COMMENT. THEY ARE NOT DECORATION — EACH ONE RECORDS A FAILURE THAT VALUE PREVENTS.
- THE RETH DEFAULTS ARE CALIBRATED FOR 12-SECOND BLOCKS. AT 0.45s THEY ARE WRONG BY ~26x. BEFORE "RESTORING A DEFAULT", WORK OUT WHAT IT MEANS IN **BLOCKS**. SEE `docs/bsc-constants.md`.

## CARGO LAYOUT
- SINGLE CRATE, NO WORKSPACE. `Cargo.lock` IS COMMITTED AND `--locked` IS THE INTENDED BUILD: THE `rex-cons` DEPENDENCY IS A GIT **TAG**, SO THE LOCK IS WHAT ACTUALLY PINS THE REVISION THE WIRE WAS TESTED AGAINST.
- BUMPING THE `reth-ext` TAG MEANS RE-RUNNING THE WIRE GUARD AGAINST A LIVE NODE IN THE SAME CHANGE. A GREEN `cargo build` PROVES NOTHING ABOUT THE WIRE.

## BEHAVIOUR
- DON'T MAKE THINGS UP. IF YOU DID NOT READ IT, IT IS NOT REAL. EVIDENCE FOR CLAIMS REQUIRED.
- QUOTE MEASUREMENTS WITH THEIR SAMPLE SIZE AND WINDOW. A NUMBER FROM A 150-SECOND WINDOW ON THIS SYSTEM IS NOISE — OBSERVED RANGE ACROSS IDENTICAL SETTLED WINDOWS WAS 0% TO 55% ON THE SAME METRIC. HOURS, NOT MINUTES.
- WHEN A FIX DOES NOT MOVE THE METRIC IT TARGETED, SAY SO AND KEEP THE MEASUREMENT. A RECORDED NEGATIVE RESULT IS WHY NOBODY RETRIES IT — SEE THE ROUND-ROBIN PEER SELECTION NOTE IN `docs/bsc-constants.md`.
- WHEN UPGRADING A PART OF THE SYSTEM, FIND EVERYTHING THAT IS NOW UNUSED AND DELETE IT.

## GIT
- DON'T PUSH, DON'T CREATE BRANCHES OR WORKTREES. WRITE ON THE CURRENT BRANCH.
- DON'T COMMIT UNLESS ASKED. WHEN ASKED, NEVER ADD A CO-AUTHOR TRAILER.
- THIS REPO IS PUBLIC — RE-READ THE FIRST PARAGRAPH BEFORE STAGING ANYTHING.
